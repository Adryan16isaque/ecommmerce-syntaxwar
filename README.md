# 👟 SyntaxWear - E-Commerce de Tênis e Sneakers

Um e-commerce moderno e responsivo para venda de tênis e sneakers online, desenvolvido com HTML5, CSS3 e JavaScript vanilla.

## 📋 Descrição do Projeto

**SyntaxWear** é uma plataforma de e-commerce especializada em tênis e sneakers de qualidade. O projeto foi desenvolvido como parte do curso **DevQuest** com foco em criação de interfaces web responsivas, componentes reutilizáveis e boas práticas de desenvolvimento frontend.

### ✨ Principais Características
- 🎯 Design responsivo e mobile-first
- 🛍️ Catálogo de produtos estruturado por categorias
- 📱 Menu hamburguer para dispositivos móveis
- 🎨 Sistema de cores e variáveis CSS bem organizado
- 🔍 Semântica HTML5 apropriada
- ♿ Estrutura acessível com ARIA labels
- 📦 Código modular e fácil de manter

## 📂 Estrutura do Projeto

```
ecommmerce-syntaxwar/
├── index.html                    # Página principal
├── README.md                     # Este arquivo
├── css/
│   ├── reset.css                # Reset de estilos padrão do navegador
│   ├── variables.css            # Variáveis CSS (cores, fontes, etc)
│   ├── base.css                 # Estilos base globais
│   ├── layout.css               # Estilos de layout
│   └── components/              # Componentes CSS reutilizáveis
│       ├── header.css           # Estilos do cabeçalho e navegação
│       ├── hero.css             # Banner principal
│       ├── product-category.css # Seção de categorias
│       ├── product-grid.css     # Grid de produtos
│       └── footer.css           # Rodapé
└── images/
    ├── logo/                    # Logo da marca
    ├── icons/                   # Ícones (hamburguer, etc)
    ├── banners/                 # Banners e imagens grandes
    ├── favicons/                # Favicons do site
    └── products/                # Imagens dos produtos
```

## 🚀 Como Usar

### 1. Clonar o Repositório
```bash
git clone <URL-do-repositorio>
cd ecommmerce-syntaxwar
```

### 2. Abrir o Projeto
Simplesmente abra o arquivo `index.html` em seu navegador:
- Clique duplo no arquivo `index.html`, ou
- Use a extensão **Live Server** no VS Code

## 📱 Responsividade

O projeto é totalmente responsivo e funciona em:
- 📱 Smartphones (320px+)
- 📱 Tablets (768px+)
- 🖥️ Desktop (1024px+)

Menu hamburguer ativa em dispositivos móveis para melhor experiência de navegação.

---

## 🎨 Paleta de Cores e Estilos

As cores e estilos são definidos em `css/variables.css`, facilitando a manutenção e padronização:

- **Cores Primárias**: Definidas como variáveis CSS
- **Tipografia**: Fontes consistentes
- **Espaçamentos**: Sistema de padding e margin padronizado
- **Breakpoints**: Pontos de quebra definidos para responsividade
